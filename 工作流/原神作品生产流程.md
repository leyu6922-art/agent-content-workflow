# 原神作品生产流程

## 总流程

```text
读取项目资料
→ 确定本期角色/主题
→ 检查素材质量
→ 判断是否值得制作
→ 制定图文方案
→ 制定动态海报方案
→ 输出提示词和发布文案
→ 用户执行生成/剪辑/发布
→ 记录复盘
```

## 阶段 1：选题

优先选题来源：

1. `未发布/` 中已有高质量角色图。
2. 热门角色、版本热点、生日、节日。
3. 元素主题：火、水、雷、冰、草、风、岩。
4. 栏目化主题：电影感海报、神级壁纸、动态封面、七国视觉重制。

选题判断标准：

- 角色辨识度强。
- 画面有清晰卖点。
- 能做动效。
- 不只是普通漂亮图。
- 有标题和配文空间。

## 阶段 2：素材筛选

检查维度：

- 分辨率：竖版优先，至少 1080×1920；更推荐 1440×2560 以上。
- 构图：主体不要太贴边，脸部和上半身清晰。
- 画面层次：前景、角色、背景最好可分离。
- 动效潜力：元素能量、头发、衣摆、光、粒子、水、火、雪、雷。
- 错误风险：手、眼睛、文字、武器、服装结构。

## 阶段 3：静态图文包装

每期至少输出：

- 主标题
- 副标题
- 角色短句
- 3-5 个备选标题
- 图文配文
- 标签
- 封面文字

标题原则：

- 不要太泛。
- 不要只写“太美了”。
- 要突出角色、氛围、元素或反差。

## 阶段 4：动态海报设计

动态海报不等于简单图片动起来。每张图应拆成：

1. 背景层：云、光、雨、雪、海浪、火焰、雷光。
2. 角色层：呼吸感、头发、衣摆、眼神光。
3. 前景层：粒子、花瓣、符文、光斑。
4. 镜头层：慢推、轻微环绕、景深变化。
5. 文字层：角色名、短标题、元素符号。

推荐时长：5-8 秒。

## 阶段 5：发布

每期至少准备：

- 视频标题
- 图文标题
- 首屏文案
- 评论区引导
- 标签

评论引导示例：

- “下一个想看谁？”
- “这个角色适合做哪种风格？”
- “要不要把这一组做成动态壁纸？”

## 阶段 6：复盘

发布后记录：

- 发布时间
- 平台
- 标题
- 封面
- 播放/阅读
- 点赞
- 收藏
- 评论
- 转发
- 用户反馈
- 下次改进

## 质量判断

### 推荐继续制作

- 角色脸部好看且稳定。
- 构图完整。
- 画面有元素动效潜力。
- 能写出明确标题。

### 谨慎制作

- 画面好看但角色辨识度弱。
- 构图太满，文字区不足。
- 动效只能做简单光效。

### 不建议制作

- 脸崩、手崩严重。
- 角色不像原神角色或同人辨识度过低。
- 画面像普通 AI 美女图。
- 缺少主题，无法栏目化。
