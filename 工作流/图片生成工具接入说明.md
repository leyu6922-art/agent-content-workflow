# 图片生成工具接入说明

## 工具位置

`C:\Users\wls\CodeBuddy\图片生成工具`

核心脚本：

`C:\Users\wls\CodeBuddy\图片生成工具\图片生成.py`

## 用途

用于把每期策划中的静态图提示词直接生成图片，并把结果保存到对应期数目录，避免散落在默认输出目录里。

## 推荐目录结构

每期作品建议这样放：

```text
D:\原神策划\每期作品\第X期-主题\
├── 策划.md
├── 静态提示词.txt
├── 动态提示词.txt
├── 生成图片\
└── 发布文案.md
```

## 推荐命令

在 PowerShell 中运行：

```powershell
cd "C:\Users\wls\CodeBuddy\图片生成工具"
python .\图片生成.py --prompt-file "D:\原神策划\每期作品\第X期-主题\静态提示词.txt" --output-dir "D:\原神策划\每期作品\第X期-主题\生成图片" --count 4 --size 2048x2048
```

## Agent 使用规则

1. 先完成该期策划，再生成图片。
2. 每期至少生成 3-4 张候选图，方便筛选。
3. 生成图必须保存到该期目录下的 `生成图片/`。
4. 生成后读取 `生成记录.json`，把模型、尺寸、提示词和结果记录到 `策划.md`。
5. 如果生成图质量不足，不要勉强进入动态海报流程，应回到提示词调整阶段。

## 注意

`.env` 中包含密钥，不要复制到 `D:\原神策划`，也不要提交或公开。
