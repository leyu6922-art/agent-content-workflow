# 原神策划项目

这个文件夹用于沉淀原神图文、动态海报、角色栏目、提示词、发布复盘和长期偏好。

## 使用方式

以后开启相关任务时，直接告诉 Agent：

> 读取 `D:\原神策划`，按项目流程帮我做这一期原神作品。

Agent 应优先读取：

1. `项目总览.md`
2. `用户画像与创作偏好.md`
3. `工作流/原神作品生产流程.md`
4. `模板/单期作品策划模板.md`
5. `.codebuddy/skills/原神内容策划Agent/SKILL.md`

## 目录说明

- `每期作品/`：每一期作品的策划、提示词、发布文案和复盘。
- `角色资料库/`：角色气质、元素、关键词、禁忌点、视觉方向。
- `提示词库/`：静态图、动态海报、封面、标题等提示词。
- `工作流/`：固定生产流程。
- `模板/`：可复制的新一期模板。
- `复盘/`：每期发布后的表现总结。
- `素材索引/`：记录外部图片素材所在位置，不复制大文件。
- `.codebuddy/skills/原神内容策划Agent/`：项目级专属 Agent 技能说明。
